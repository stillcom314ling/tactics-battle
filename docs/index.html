Raylib-cs Example

A minimal C# Raylib project built via GitHub Actions

About

This is a minimal example demonstrating a C# + Raylib-cs project compiled and deployed through GitHub Actions.

The game opens an 800x450 window with a bouncing ball and text overlay — built with .NET 8 Raylib-cs 7.

Download & Run (Linux x64)

  • Download the RaylibGame binary from the latest GitHub Actions run (artifacts section).
  • Make it executable: chmod +x RaylibGame
  • Run it: ./RaylibGame

Requires a display (X11 or Wayland). Built as a self-contained binary — no .NET runtime needed.

Stack

  • Language: C# / .NET 8
  • Graphics: Raylib-cs 7.0.0 (bindings for raylib)
  • CI/CD: GitHub Actions — dotnet restore → build → publish
  • Deploy: GitHub Pages (this page)
